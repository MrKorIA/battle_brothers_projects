# Проект: mod_horde_invasion (Нашествие Желёной Орды)

Мод кризиса для Battle Brothers (Squirrel, .nut). Создаётся с нуля по TZ.md.
Структура мода — по образцу bb_vanilla_plus.

## Зависимости (обязательные, мод без них не работает)

- **mod_Jurchen** (`Z:\GameMods\Battle Brothers\mods\battle_brothers_projects\mod_Jurchen`) — юниты, лагерные шаблоны, именное оружие, бочки пороха
- **Scourge of God** (`Z:\GameMods\Battle Brothers\mods\battle_brothers_projects\mod_Scourge_of_God`) — юниты Mgl, именное оружие

Референсы и ваниль: распакованная ваниль — `Z:\GameMods\Battle Brothers\mods\!project\data_014`.

## Структура

- `mod_horde_invasion/` — хуки мод-системы (`!mods_preload`-стиль как в bb_vanilla_plus: `mod_vanilla_plus/hooks` + загрузчик)
- `scripts/` — игровой контент: конфиги кризиса, контракты, амбиции, фракции
- `docs/` — правила и гайды (см. ниже)
- `TZ.md` — техническое задание (источник истины по составу мода)

## Правила работы

- **Жёсткое правило API:** не выдумывать функции/константы/сигнатуры; каждое сомнительное использование проверять grep'ом по `data_014` или данным пользователем референсам. Иначе — спросить.
- **Тексты** (контракты, события, описания): перед генерацией/правкой читать `docs/texts/text_generation.md` и `docs/texts/text_validation.md`; проверка — отдельным проходом по чек-листу.
- **Локации/скриптованные бои** (лагеря орды, контракт с порохом): читать `docs/locations/tactical_location_guide.md` + чек-лист `docs/locations/tactical_location_checklist.md`.
- Новые .nut после правок — через чекер баланса скобок/строк.
- Порядок записей в реестрах-конфигах не менять (сейвы); новое — в конец.
- Минимальные изменения; стиль — как в соседних файлах проекта/референса.
- Сборка — только по явной просьбе пользователя, при закрытой игре (см. корневой build.sh монорепозитория, список папок актуализировать по мере роста мода).

## Сборка

- `build.bat` — упаковка в `mod_horde_invasion.zip` через корневой build.sh монорепозитория → `Z:\SteamLibrary\steamapps\common\Battle Brothers\data`. ЗАПРЕЩЕНО запускать автоматически.
